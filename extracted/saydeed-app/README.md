# Saydeed App (design)

Extracted on 2026-10-11 from https://claude.ai/artifact/5BSJ2bRMbC2WriZGBtT8XM (version 1791669222-3f40),
then extended locally the same day with the Marketplace (phone and web) and renamed to Saydeed.
`project/support.js` is a copy of `artifact-type/dc-runtime.js`, which the Claude canvas serves under that
name at runtime. Everything in `artifact-type/` is the canvas viewer as published, unchanged.

## What is here

- `project/*.dc.html`: the boards, laid out by `project/canvas.json`
  - `IA` 00 · Information architecture (1800 × 1220), including the Marketplace and the web app
  - `Main` 01 · Brain Map (home), `Dashboard` 02, `Chat` 03 · Let's Chat, `Call` 04 · Interactive Call
  - `Sidebar` 05 (Marketplace in both Work and Code), `Hub` 06 · Inbox, `Approval` 07, `Create` 08
    (Marketplace and Sell what you built tiles) (all 390 × 844)
  - `Marketplace` 09 (Buy and Sell tabs, search, category chips; any listing opens in place),
    `MarketItem` 10 · Listing (plans, permissions, buy flow ending in Installed),
    `MarketSell` 11 · Sell what you built (pick, price and name, privacy check, Submitted for review)
  - `WebHome` 12, `WebInbox` 13, `WebMarketplace` 14, `WebMarketItem` 15, `WebMarketSell` 16: the web app as
    1440-wide fill pages. Each has the left rail and the top bar (search, Chief of Staff, Inbox, Create);
    at phone width the rail becomes one scrolling row above the page
  - `Brain` Component · Brain orb (340 × 340), imported by Main, Call and IA
  - `WebRail` Component · Web nav rail (248 wide, `active` prop) and `WebTopBar` Component · Web top bar,
    imported by every web page. WebRail is generated by `.unlazy/saydeed-marketplace-2026-10-11/checks/gen-rail.mjs`
- `index.html` and `artifact-type/`: the canvas viewer and its reference notes, as published.

Marketplace categories: workflows, agents and skills, pipelines, tools, and experts (people who set
things up). Listings, sellers, prices and ratings are example data, like the rest of the boards.
`MarketItem` and `WebMarketItem` each hold the full example catalogue, and `Marketplace` and
`WebMarketplace` each hold its summary, because a board's script cannot import another file. Change
a listing in all four.

## Colours

Since 2026-10-11 every board uses the saydeed.com palette (app/globals.css): ground #EEF5F9, surfaces #FFFFFF,
inset #E3EFF5, hairline #C9DCE5, ink #102A39 / #2D4858 / #405C6B, muted #4F6875, signal #086B91 (hover #064F6B,
tint #D6EFF8), amber hold #9A5A00 (tint #FFE9C2), success #13764A (tint #DDF2E6). The first dark build is archived
in .unlazy/saydeed-marketplace-2026-10-11/themes/dark-original-backup.

## Viewing

Boards import each other with `<dc-import>`, which fetches files, so open them over HTTP rather than
`file://`. Serve this folder (for example `npx serve -l 8765 .`) and open `preview.html`, which lays the
boards out as `canvas.json` does, with a Screens view that lists them one by one. `preview.html` is not
part of the original artifact.
